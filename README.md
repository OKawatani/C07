# Informações sobre o projeto.

### Tema: Inventário de RPG.
O projeto consiste na modelagem e implementação de um banco de dados para gerenciar o sistema de inventário de um jogo de RPG. O sistema permite armazenar e controlar itens (armas, armaduras, poções, artefatos, etc.), personagens/jogadores, e a relação entre eles — como itens equipados, itens carregados no inventário, quantidade, peso, raridade e atributos especiais. O objetivo é representar de forma estruturada as regras de um jogo de RPG, permitindo consultas como: quais itens um personagem possui, qual a capacidade de carga disponível, quais itens estão à venda em uma loja, entre outras funcionalidades comuns a esse tipo de sistema.
